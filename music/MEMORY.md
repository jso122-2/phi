# MEMORY

#hub

Hub shard 7 — long-term session history and listening pattern depth.

Injected by callers that track session state:

    ring.inject("MEMORY", memory_signal)

where `memory_signal` is a [0, 1] value encoding how far into a long
listening session the current track sits — deeper sessions produce
stronger MEMORY activation, surfacing more historical vault context.

## Spoke context

Notes linked here describe long-term listening patterns, repeat-artist
histories, session arc analysis, and time-of-day or seasonal patterns.
Session log files from `sessions/` can be soft-linked here.

## Physics

Basin centre 15.68 = 8·α. Shard 7 is antipodal to ENERGY (shard 3)
under the 8-shard ring — strong MEMORY activation inhibits the ENERGY
hub, which makes physical sense: deep historical context shifts focus
away from raw kinetic energy.

(imported from `_constants.py`), shard 7 maps to URGENT. MEMORY
