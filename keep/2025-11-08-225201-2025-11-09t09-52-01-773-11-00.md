**CONTEXT PROMPT: POKER BOT VISION ARCHITECTURE**

-----

## **SYSTEM OVERVIEW**

Building a poker bot vision system using **ensemble of micro-CNNs** instead of brittle OCR. Architecture has 4 distinct layers:

1. **Region Detection** (global vision - WHERE things are)
1. **Region Classification** (selector - WHICH micro-CNN to use)
1. **Micro-CNN Execution** (specialists - WHAT each region contains)
1. **Meta-Aggregator** (integration - combines outputs into game state)

-----

## **LAYER 1: REGION DETECTION**

**Purpose:** Analyze full screenshot, locate all regions of interest (ROIs)

**Input:** Raw screenshot (1920×1080 or poker client resolution)

**Output:** List of detected regions with bounding boxes and types

```python
regions = [
    {'bbox': (100, 200, 50, 30), 'type': 'button', 'id': 'btn_1'},
    {'bbox': (160, 200, 50, 30), 'type': 'button', 'id': 'btn_2'},
    {'bbox': (50, 400, 30, 40), 'type': 'card', 'id': 'card_1'},
    {'bbox': (300, 300, 80, 40), 'type': 'chip_stack', 'id': 'chips_1'},
    # ... 10-20 regions per screenshot
]
```

**Implementation options:**

- **Template matching** (fastest, works if UI is static)
- **OpenCV edge detection + contours** (robust to minor UI changes)
- **Lightweight object detector** (YOLO-tiny, learned approach)

**Key requirement:** Must have spatial awareness of full screen layout

-----

## **LAYER 2: REGION CLASSIFICATION (REVOLVER CHAMBER SELECTOR)**

**Purpose:** For each detected region, select the appropriate micro-CNN

**Analogy:** Chambered revolver - each region type loads specific micro-CNN

**Logic:**

```python
def select_micro_cnn(region_type):
    cnn_map = {
        'button': button_state_cnn,
        'card': [card_rank_cnn, card_suit_cnn],  # Run both
        'chip_stack': chip_count_cnn,
        'player_avatar': player_state_cnn,
        'pot_display': pot_size_cnn,
        # ... 10-15 total micro-CNNs
    }
    return cnn_map[region_type]
```

**Output:** Assignment of micro-CNN(s) to each detected region

-----

## **LAYER 3: MICRO-CNN EXECUTION**

**Purpose:** Narrow, shallow specialist CNNs that classify specific visual elements

**Design principles:**

- **Narrow:** Each CNN solves ONE specific task (button state, card rank, chip count, etc.)
- **Shallow:** Small architecture (3-5 conv layers, <1M params each)
- **Fast:** <1ms inference per CNN
- **Confident:** Each outputs classification + confidence score

**Architecture example (Button State CNN):**

```python
class ButtonStateCNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv = nn.Sequential(
            nn.Conv2d(3, 16, 3, padding=1),  # Input: 64×64×3
            nn.ReLU(),
            nn.MaxPool2d(2),  # → 32×32×16
            nn.Conv2d(16, 32, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # → 16×16×32
            nn.Conv2d(32, 64, 3, padding=1),
            nn.ReLU(),
            nn.MaxPool2d(2),  # → 8×8×64
        )
        self.fc = nn.Sequential(
            nn.Flatten(),
            nn.Linear(8*8*64, 128),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(128, 5)  # Classes: fold, call, raise, check, disabled
        )
    
    def forward(self, x):
        return self.fc(self.conv(x))
```

**Micro-CNN inventory (10-15 total):**

1. Button State (fold/call/raise/check/disabled)
1. Card Rank (A/K/Q/J/10/9…2)
1. Card Suit (♠♥♦♣)
1. Chip Count (regression or bins)
1. Player State (folded/in_hand/acting/waiting)
1. Pot Size (displayed number)
1. Community Card Presence (flop/turn/river detection)
1. Dealer Button Position
1. Player Action Indicator (bet/raise/check text)
1. Timer/Clock State
   11-15. Additional edge cases as discovered

**Training:** 500-1000 synthetic + augmented images per micro-CNN, <1 hour training each

**Output format:**

```python
{
    'region_id': 'btn_1',
    'cnn_type': 'button_state',
    'prediction': 'fold',
    'confidence': 0.95,
    'raw_logits': [0.95, 0.02, 0.01, 0.01, 0.01]
}
```

## **LAYER 4: META-AGGREGATOR**

**Purpose:** Combine all micro-CNN outputs into coherent global game state

**NOT:** Decides which micro-CNN to use (that’s Layer 2)

**YES:** Integrates all specialist outputs into unified world model

**Two implementation approaches:**

### **APPROACH A: RULE-BASED AGGREGATOR (START HERE)**

Simple Python logic that combines outputs based on confidence thresholds

```python
def meta_aggregate(all_micro_outputs):
    # Filter high-confidence outputs
    trusted = [o for o in all_micro_outputs if o['confidence'] > 0.8]
    
    # Build semantic units
    buttons = [o for o in trusted if o['cnn_type'] == 'button_state']
    available_actions = [b['prediction'] for b in buttons]
    
    card_ranks = [o for o in trusted if o['cnn_type'] == 'card_rank']
    card_suits = [o for o in trusted if o['cnn_type'] == 'card_suit']
    hero_hand = pair_cards_by_position(card_ranks, card_suits)
    
    chips = [o for o in trusted if o['cnn_type'] == 'chip_count']
    pot_estimate = sum([c['prediction'] for c in chips])
    
    # Construct game state
    game_state = {
        'available_actions': available_actions,
        'hero_hand': hero_hand,
        'pot_size': pot_estimate,
        'community_cards': extract_community_cards(trusted),
        'players_in_hand': count_active_players(trusted),
        'system_confidence': np.mean([o['confidence'] for o in trusted]),
        'timestamp': time.time()
    }
    
    return game_state
```

**Pros:** Simple, interpretable, no training needed

**Cons:** Manual logic, doesn’t learn optimal combinations

### **APPROACH B: META-LEARNER (ADVANCED, OPTIONAL)**

Small neural network that learns optimal combination strategy

```python
class MetaLearner(nn.Module):
    def __init__(self, num_micro_cnns=15, classes_per_cnn=5):
        super().__init__()
        # Input: Concatenated outputs from all micro-CNNs
        # Each micro-CNN gives: [class_probs (5) + confidence (1)] = 6 values
        # 15 micro-CNNs × 6 = 90-dimensional input vector
        
        self.fc = nn.Sequential(
            nn.Linear(90, 128),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(128, 64),
            nn.ReLU(),
            nn.Linear(64, game_state_dim)  # Output: full game state vector
        )
    
    def forward(self, concatenated_micro_outputs):
        return self.fc(concatenated_micro_outputs)
```

**What it learns:**

- Context-aware weighting (trust button-CNN more in certain lighting)
- Contradiction resolution (if two CNNs disagree, which to trust)
- Correlation patterns (“bet increase + button disabled = likely raised”)

**Training requirements:**

- 1000+ labeled screenshots with ground truth game states
- More complex but potentially more robust

**Start with Approach A, upgrade to B only if needed**

## **FULL PIPELINE EXECUTION**

```python
def process_screenshot(screenshot):
    # Layer 1: Detect regions
    regions = detect_regions(screenshot)
    
    # Layer 2 & 3: Select and execute micro-CNNs
    micro_outputs = []
    for region in regions:
        crop = screenshot[region['bbox']]
        cnn = select_micro_cnn(region['type'])
        
        if isinstance(cnn, list):  # e.g., card needs rank + suit
            for sub_cnn in cnn:
                output = sub_cnn(crop)
                micro_outputs.append({
                    'region_id': region['id'],
                    'cnn_type': sub_cnn.name,
                    'prediction': output['class'],
                    'confidence': output['confidence']
                })
        else:
            output = cnn(crop)
            micro_outputs.append({
                'region_id': region['id'],
                'cnn_type': cnn.name,
                'prediction': output['class'],
                'confidence': output['confidence']
            })
    
    # Layer 4: Aggregate into game state
    game_state = meta_aggregate(micro_outputs)
    
    return game_state
```

## **KEY ADVANTAGES OVER OCR**

1. **Robustness:** CNNs learn visual patterns, not text parsing (handles lighting, fonts, anti-aliasing)
1. **Modularity:** Add new edge case = train new micro-CNN, plug in, no retraining pipeline
1. **Debugging:** Issue with button detection? Fix button-CNN in isolation
1. **Speed:** 10-15 micro-CNNs at <1ms each = <15ms total (60+ FPS possible)
1. **Confidence:** Each micro-CNN reports certainty, system can fallback or skip low-confidence frames
