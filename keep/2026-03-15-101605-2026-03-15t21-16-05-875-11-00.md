ASCII GENERATION ARCHITECTURE
DAWN project — scripts/ascii_graph/
Audited 2026-03-15
================================================================================

OVERVIEW
--------
The ASCII generation system lives in scripts/ascii_graph/ and is exposed
through a single unified CLI at scripts/ascii_graph/generate.py.
Five distinct rendering pipelines feed into it. All share a common
image-to-ASCII converter (img2ascii.py) and character vocabulary.

A secondary standalone renderer exists at
scripts/utilities/fractal_art/graff_render.py (predates the package,
uses its own simpler pipeline).

Post-processing tools for zine output live at scripts/denoise_*.py.

SHARED CONSTANTS  (__init__.py)
-------------------------------
  GRID_W          200 chars
  GRID_H           50 chars
  DENSITY_RAMP    " .:-=+*#%@"   (10 levels, index 0=space 9=@)
  ASCII_VOCAB     " .:-=+*#%@/\|_-()"  (17 chars, used by CGT head)
  STYLES          [synthetic, wildstyle, bubble, throw-up,
                   blockbuster, chrome, 3D]   (7, maps to style_id)
  EDGE_CLASSES    [none, horizontal, vertical, diag_right, diag_left,
                   corner_tl, corner_tr, corner_bl, corner_br]   (9)

================================================================================
PIPELINE 1: ATLAS  (default, --font / --style)
================================================================================

glyph_atlas.py
  Purpose:  Pre-render A-Z from system TTF fonts into character templates.
  Fonts:    17 search paths (DejaVu, FreeFont, Liberation, Lato, JetBrains,
            Nimbus, URW families). Loads all that exist.
  Per glyph:
    - PIL renders char at font_size=200 onto 400×400 L canvas
    - Crops to content bounding box + 1px padding
    - Resizes to GRID_H rows, width = GRID_H * aspect * 0.55 (corrects
      for terminal char cell aspect ratio)
    - Maps pixel brightness → DENSITY_RAMP index → char string
    - Returns list[str] of height rows
  Output:   {font_name: {letter: list[str]}}  (module-level cache)

compose.py
  compose_word(word, font, width, height, spacing)
    - Looks up each letter in atlas, concatenates horizontally with spacer
    - Centers result in target grid (200 wide)
    - Returns list[list[str]]  (H rows × W cols)

  apply_style(grid, style)
    "clean"   → identity (atlas chars as-is)
    "graph"   → remap: collapses to bold %@# aesthetic
    "heavy"   → remap: shifts every char one step denser
    "outline" → fills empty cells adjacent to non-space with "."
    "shadow"  → draws dimmed copy at (+2, +2) offset behind letters

  grid_to_text(grid) → string (trims trailing space, blank leading/trailing rows)
  grid_to_density / density_to_grid → float array bridge for blending

blend.py  (optional LoRA texture injection)
  from_image(lora_png, base_grid, alpha)
    - Opens PNG, resizes to grid dims, maps brightness → DENSITY_RAMP
    - Extracts letter mask from base_grid (density >= 1)
    - alpha=1.0: replaces letter cells with LoRA chars directly
    - alpha<1.0: interpolates density arrays, converts back via DENSITY_RAMP

CLI flags: generate.py --font <partial_name> --style <clean|graph|heavy|outline|shadow>
           --lora-image <png> --lora-alpha 0.0-1.0 --spacing N

================================================================================
PIPELINE 2: THROWIE  (--throwie)
================================================================================

throwie.py

render_throwie_image(word, canvas_w, canvas_h, stroke_width)
  1. Binary-search largest font_size that fits canvas with stroke margin
  2. PIL renders word as binary mask (fill=True / bg=False)
  3. Gaussian blur radius=1.0 → fill_mask (arr > 128)
  4. scipy.binary_dilation with circular structuring element → stroke_mask
  5. Composite:
       stroke_mask & ~fill_mask → pixel value 0   (pure black = outline zone)
       fill_mask                → pixel value 80  (mid grey = fill zone)
       background               → pixel value 255 (white = bg)
  6. Final Gaussian blur 0.8
  Returns: greyscale PIL Image

image_to_throwie_ascii(img, width, style)
  1. Calls img2ascii.image_to_ascii_zone() with:
       edge_thresh=0.25, bg_thresh=0.90, smooth_radius=1,
       dither=0.05, directed_edges=False, fill_texture=False
  2. Zone remap (10→3):
       zones 0-2 (bg/near-bg)  → " "
       zones 3-5 (fill, 80/255 grey lands here) → fill_char
       zone  6   (transition)  → inner_char
       zones 7-9 (stroke, 0 black lands here)   → outline_char

Styles and their chars:
  bubble   fill=% inner=# outline=@  ramp=" .:=#%@"
  chrome   fill== inner=% outline=@  ramp=" .:-=*#%@"
  fill     fill=# inner=% outline=@  ramp=" .:=#%@"
  outline  fill=. inner== outline=@  ramp=" .:-=+#@"

Canvas sizing: canvas_w = max(900, width*10)
               canvas_h = canvas_w × target_rows / (width × aspect)
               stroke_width = max(12, canvas_h * 0.055)

CLI flags: generate.py --throwie <bubble|chrome|fill|outline>
           --throw-width N  --throw-all

PIPELINE 3: PHOTO-STYLE  (--photo-style)
================================================================================

style_db.py
  STYLE_NAMES = [chrome, outline, fill, night, pastel, tag]
  Scans graffiti photo dataset at ~/graffiti_lora_treks/preprocess/cropped
  Classifies into styles by brightness/contrast heuristics
  Caches results in scripts/ascii_graph/style_index.json
  TAG_ASCII_DIRS: docs/zine/tags_photo/, docs/zine/tags_ascii/
    (curated tag ASCII files for "tag" style)

  zone_params(style) → per-style img2ascii parameters:
    chrome:  edge_thresh=0.18 bg_thresh=0.85 dither=0.30 directed=True
    outline: edge_thresh=0.15 bg_thresh=0.92 dither=0.10 directed=True
    fill:    edge_thresh=0.25 bg_thresh=0.88 dither=0.20 directed=True
    night:   edge_thresh=0.22 bg_thresh=0.78 dither=0.25 directed=True invert=True
    pastel:  edge_thresh=0.12 bg_thresh=0.95 dither=0.15 directed=False
    tag:     served from raw ASCII files directly

batch_convert.py
  isolate_graffiti(img, bg_value)
    Strips wall/sky background: keeps only paint pixels
    Uses colour/saturation/brightness segmentation

photo_style.py — render_photo_style(word, style, font, width, height,
                                    texture_mode, edge_overlay, seed)
  Step 1: compose_word(word, font, width, height, spacing=2)  → base grid
  Step 2: pick_image(style, seed) from style_index.json       → ref image path
  Step 3: isolate_graffiti(ref_img, bg=0|255)                 → clean paint
  Step 4: image_to_char_grid(ref_img, mode=density|zone)      → texture grid
  Step 5: apply_photo_texture(base, texture, mode=tile|sample|zone, seed)
            tile:   wraps/tiles texture over letter mask
            sample: randomly samples heavy chars from texture palette
            zone:   maps texture coords to letter coords proportionally
  Step 6: apply_edge_layer() if edge_overlay
            directional chars (/, \, |, -) at letter perimeter cells
  → grid_to_text()

"tag" style bypass:
  render_tag_style() loads a random pre-rendered ASCII file from
  docs/zine/tags_photo/ or docs/zine/tags_ascii/

CLI flags: generate.py --photo-style <chrome|outline|fill|night|pastel|tag>
           --texture-mode <tile|sample|zone>  --edge  --seed N
           --width N --height N  --all-styles

PIPELINE 4: HEAD-FONT  (--head-font / --bubble)
================================================================================

head_font.py

Font discovery: searches FONT_SEARCH_PATHS + ~/.fonts + ~/.local/share/fonts
for bold/black/heavy/extrabold TTF/OTF files.

render(text, style, font_path, ascii_width)
  Applies transforms in order (all optional, controlled by STYLE_PRESETS):

  _render_text_bitmap(text, font_path, font_size, padding)
    PIL renders black text on white L canvas

  _apply_dot_fill(img)        → binary erosion interior → dot grid pattern
  _bubble_gradient(img)  OR
  _add_outline(img)           → see below
  _apply_bevel(img)           → interior depth: lighter near edges, darker center
  _apply_halftone(img)        → sinusoidal pattern modulates interior brightness
  _extrude_3d(img)            → stepped extrusion with gradient shading
  _add_shadow(img)            → drop shadow via shifted mask + Gaussian blur
  _apply_skew(img)            → affine horizontal shear (italic)
  _apply_rotation(img)        → PIL rotate with canvas expand
  _apply_perspective(img)     → PIL perspective transform (4 directions)

  Output mode:
    density_mode=True  → image_to_ascii(img, mode="density", ramp="graph",
                          invert=True)   [used by bubble presets]
    invert=True        → _render_dot_matrix() [dot-field with text as neg space]
    default            → image_to_ascii(img, mode="zone", dither=cfg.dither)

_bubble_gradient(img, outer_radius, curve)
  KEY for Tags-001 aesthetic:
  - scipy.distance_transform_edt on text_mask and ~text_mask
  - Outside band (0 < dist_out <= outer_radius):
      brightness = 40 + t^1.8 * 215  (boundary=40, edge=255)
  - Inside (dist_in > 0):
      brightness = 40 * (1 - t^0.4)  (boundary=40, center=0)
  → smooth concentric gradient, darkest at stroke center (@@@), fades to space

_add_outline(img, thickness, hollow, curve)
  - dist transform outside text → linear/squared/sqrt gradient in band
  - hollow=True: gradient ring on both sides, interior becomes white

20 STYLE_PRESETS including:
  Zone-mode presets:  wireframe, bold, shadow, 3d, perspective, vanish-right,
                      vanish-bottom, tilt, italic, halftone, dot-fill, stencil,
                      dense, inverted, block
  Bubble presets:     bubble, bubble-3d, bubble-shadow, bubble-perspective,
                      bubble-halftone
                      (font_size 500-600, bubble_mode=True, density_mode=True)

CLI flags: generate.py --head-font <style>  --bubble  --bubble-all
           --hf-all  --hf-width N

================================================================================
PIPELINE 5: CGT MODEL  (--model / --cgt)
================================================================================

model.py — CharacterGridTransformer

WordEncoder
  char_embed:  Embedding(28, 256)   [26 letters + space + unknown]
  style_embed: Embedding(7, 256)    [7 STYLES]
  pos_embed:   Embedding(17, 256)   [style token + 16 char positions]
  transformer: 4-layer TransformerEncoder (d=256, heads=8, FFN=1024, GELU,
               batch_first=True)
  Input:  word_ids (B,16) + style_ids (B,) → seq [style_tok | char_toks]
  Output: (B, 17, 256) encoded sequence

CNNGridDecoder
  col_project: Linear(256, 256 * 10)
    each token → column of shape (ch=256, init_h=10)
    → (B, 256, 10, 17)  [feature map: height=10, width=17 columns]

  upsample_h:
    ConvTranspose2d 10→20 (stride_h=2) + ResBlock
    ConvTranspose2d 20→40 (stride_h=2) + ResBlock
    → (B, 128, 40, 17)

  upsample_w:
    ConvTranspose2d 17→34 (stride_w=2)
    ConvTranspose2d 34→68 (stride_w=2)
    → (B, 64, 40, 68)

  F.interpolate bilinear → (B, 64, GRID_H=50, GRID_W=200)
  refine: ResBlock + Conv2d + BatchNorm + ResBlock

MultiHeadOutput
  density_head: Conv2d(64,64,3) + GELU + Conv2d(64, 10, 1)
  edge_head:    Conv2d(64,64,3) + GELU + Conv2d(64,  9, 1)
  char_head:    fuse(64+10+9→64) + GELU + Conv2d(64, 17, 1)
                [char head gets softmax density + edge as conditioning]
  → density (B, 10000, 10)  edge (B, 10000, 9)  chars (B, 10000, 17)

train.py
  Loss = w_d * CE(density) + w_e * CE(edges) + w_c * CE(chars)
         + w_s * StructuralLoss
  StructuralLoss: penalizes local density variance (isolated chars, jagged contours)
  Class weights: background (index 0) downweighted to 0.1
  AMP (torch.autocast) supported

dataset.py — ASCIIGraphDataset
  JSON records: {word, style, density[H×W], edges[H×W], chars[H×W]}
  Augment: horizontal flip, row/col jitter, density noise
  Data dir: data/ascii_graph/
  Checkpoint: config/ascii_graph_checkpoints/best.pt

Generation (--cgt):  density_mode=True, argmax or temperature sampling

CORE IMAGE CONVERTER  (img2ascii.py)
================================================================================

Used by: throwie, photo_style, head_font pipelines

image_to_ascii_zone(img, width, aspect_correction=0.45, ...)
  1. Convert to L, resize: new_h = width * (orig_h/orig_w) * 0.45
  2. MedianFilter smooth (default radius=2)
  3. Percentile normalise [2nd–98th] if range > 10
  4. Sobel edges: sx/sy components + magnitude (all normalised 0..1)
  5. Quantize to 10 zones:
       0  bg         brightness >= bg_thresh (default 0.88)
       1  faint      < bg_thresh * 0.82
       2  light      < bg_thresh * 0.68
       3  mild fill  < bg_thresh * 0.55
       4  mid fill   < bg_thresh * 0.42
       5  heavy fill < bg_thresh * 0.30
       6  dense fill < bg_thresh * 0.20
       7  edge-light < bg_thresh * 0.12
       8  edge-heavy < bg_thresh * 0.05
       9  edge-max
       + strong_edge (mag >= edge_thresh)  → zone max(current, 9)
       + mid_edge (>= thresh*0.6)          → zone max(current, 8)
       + mild_edge (>= thresh*0.35)        → zone max(current, 7)
  6. Optional dither: local variance mask, bounded noise shifts zone ±1
  7. Map zones → ZONE_RAMP chars: " .:-=+*#%@"
  8. Optional fill_texture: zones 1-6 get variant sets
       zone 1: ...'   zone 2: ::;,   zone 3: --~   etc.
  9. Optional directed_edges: Sobel angle → perpendicular char
       zone 7 → - | / \
       zone 8 → = # % #  (heavier versions)
       zone 9 → @

image_to_ascii(img, mode="zone"|"density", ...)
  zone:    routes to image_to_ascii_zone()
  density: legacy per-pixel → ramp index (no edge detection)
  RAMPS: graph " .:-=+*#%@",  block " ░▒▓█",
         simple " .:-=+*#@",  detailed (70-char fine ramp)

ZINE POST-PROCESSING  (scripts/denoise_*.py)
================================================================================

These operate on raw ASCII input (docs/zine/raw_ascii_input.txt) and
produce filtered variants for the SCHEMA zine layout.

denoise_ascii.py     — three passes: %@ / %@# / %@#*   (progressive denoising)
denoise_preserve.py  — denoising that preserves structural segments
denoise_rotate.py    — same with rotational orientation preserved

All use: extract(lines, keep_chars) — keep only specified chars, space the rest,
         trim blank rows, strip common leading indent.

LIVE VIEWER  (scripts/ascii_graph/graff_live.py)
================================================================================

Interactive terminal viewer cycling all styles:
  ALL_STYLES = photo_styles + bubble_presets + ["CGT"]
Controls: type word, Tab/Shift+Tab cycle style, Enter re-rolls seed, q quits
Quit: q/Q/Escape via tty.setcbreak + select.select (SIGINT fallback)
Loads CGT model lazily on first request.

================================================================================
STANDALONE EARLY RENDERER  (scripts/utilities/fractal_art/graff_render.py)
================================================================================

Predates the ascii_graph package. Simpler pipeline:
  PIL render (Lato-Black / DejaVuSans-Bold) → Sobel edges + brightness →
  custom palette fill (PALETTE_FILL / PALETTE_EDGE) → ASCII string

Not integrated with the package; produces SCHEMA-TAG-005 style output.
No style_db, no atlas, no CGT.
