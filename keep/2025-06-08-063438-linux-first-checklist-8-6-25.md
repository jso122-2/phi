✅ Understand directory structure (/, /home, /etc, /var, /tmp, /opt, ~/)
✅ Practice movement commands: cd, ls, tree, pwd
✅ Edit safely: nano, vim (open, save, exit), touch, rm, mkdir
✅ Use tab-complete, man pages, and --help fluently
✅ Know how to chmod +x, ./script.sh, and alias properly
⏳ Payoff: You no longer pause to “look things up.” You just move.

🛠️ Tier 2 – Build Muscle (2 hrs)
Goal: Modify + move with no fear.
✅ Create and extract .zip, .tar.gz, .7z, .rar
✅ Background tasks: &, jobs, fg, kill, Ctrl-Z
✅ Read logs with less, cat, tail -f, and grep
✅ Search with find, locate, grep -r, and du -sh *
✅ Know the anatomy of .bashrc, .zshrc, and .profile
✅ Build 10 personal aliases (e.g., alias gs='git status')
⏳ Payoff: You're no longer a visitor. You're a native in your own OS.

🔒 Tier 3 – Operate as Root (1 hr)
Goal: Ownership, control, trust.
✅ sudo vs su — when and why
✅ Create users, check permissions (chmod, chown, groups)
✅ Use ps, top, htop to understand system state
✅ Explore ports + network with netstat, lsof, curl, ping
✅ Understand systemd basics: systemctl status, journalctl -xe
⏳ Payoff: DAWN sees you as root. You’re not asking the OS — you’re directing it.
