========================================================================
THE 7 WALL PRIMITIVES
========================================================================

These are the mathematical equations that make the pocket walls fold,
twist, nuzzle, glow, and remember.  They work together: the structural
fold defines shape, the cosine drape adds texture, the fold gradient
detects boundaries, proximity amplifies near rattling points, temporal
decay adds memory, multi-scale blends resolution, and edge rattle adds
quantum-like oscillation.

1. STRUCTURAL FOLD  W(r,θ,p)
   ──────────────────────────────────────────────────────────────────

   Formula:
     wall = Σ_s [ cos(r·π·s/2) · sin(θ + p·π/11) ] / s

   Variables:
     r     = radial distance from center = √(x² + y²)
     θ     = angular position = atan2(y, x)
     p     = cliff position ∈ [0, 22]
     s     = scale ∈ {1, 2, 4, 8}  (4 recursive layers)

   How it works:
     At each scale s, a half-circle cos(r·π·s/2) is twisted by
     sin(θ + p·π/11).  The position p rotates the twist angle so
     each cliff position has a unique wall orientation.  Dividing
     by s gives finer scales less weight — natural recursive nesting.

   The wall field W is normalised to [0, 1] after summation.

2. COSINE DRAPE  D(r,s,χ)
   ──────────────────────────────────────────────────────────────────

   Formula:
     drape = [ cos(r·s·χ) − cos(r·s·χ + 0.01) ] × 100

   Variables:
     r     = radial distance
     s     = scale ∈ {1, 2, 4, 8}
     χ     = Ana-Chi value ∈ [0.03, 2.67]
     0.01  = the "impossibly close" delta

   How it works:
     Two cosines separated by 0.01 radians are subtracted.  The
     result is nearly zero everywhere EXCEPT where the cosine is
     changing rapidly — those positions produce visible ripples.
     The ×100 amplification makes these whisper-thin differences
     visible.  Higher χ → tighter oscillation → denser nuzzling.

   This is the "felt texture" — not noise but mathematically
   derived from the pocket geometry itself.

3. FOLD GRADIENT  ∇F(I)
   ──────────────────────────────────────────────────────────────────

   Formula:
     fold_strength = √( (∂I/∂x)² + (∂I/∂y)² )

   Variables:
     I     = iteration count field (Julia set escape counts)
     ∂I/∂x = horizontal gradient (torch.gradient dim=2)
     ∂I/∂y = vertical gradient (torch.gradient dim=1)

   How it works:
     The gradient magnitude of the iteration field.  Where iteration
     counts change sharply between neighbouring pixels = a fold.
     These are the beautiful contour lines wrapping the fractal.

   Attractor sensitivity modulates visibility:
     fold_visible = fold^(1/sensitivity)
     Higher sensitivity → lower exponent → more folds visible.

4. RATTLING PROXIMITY  P(χ)
   ──────────────────────────────────────────────────────────────────

   Formula:
     proximity = e^( −|χ − χ_rattle| / 0.5 )

   Variables:
     χ         = current Ana-Chi value
     χ_rattle  ∈ {0.99, 1.96, 2.67}  (the 3 rattling pockets)
     0.5       = decay half-width

   How it works:
     Exponential decay from each rattling pocket.  At the rattle
     itself, proximity = 1.0 (full amplification).  At distance 0.5
     from the nearest rattle, proximity ≈ 0.37.  At distance 1.0,
     proximity ≈ 0.14.

     Total fold amplification = 1 + (attractor_amp − 1) × proximity.
     This makes folds GLOW when you're near a rattling pocket.

5. TEMPORAL DECAY  M(t,g)
   ──────────────────────────────────────────────────────────────────

   Formula:
     decay_rate = 0.90 + clamp(gravity/5, 0, 1) × 0.08
     memory(t+1) = memory(t) × decay_rate

   Variables:
     gravity    = attractor gravity strength ∈ [0.1, 5.0]
     decay_rate = per-frame memory retention ∈ [0.90, 0.98]
     t          = frame number

   How it works:
     Walls remember where you've been.  Each visit sets
     memory = max(memory, current_folds × activation_strength).
     Between visits, memory decays per-frame by the decay rate.

     Attractor gravity controls decay speed:
       true_center (g ≈ 1.0) → decay = 0.916  (slow fade)
       escape      (g ≈ 0.1) → decay = 0.902  (fast fade)

     Output blend:
       visible_folds = 0.6 × current_folds + 0.4 × memory_folds

6. MULTI-SCALE FOLD  F_ms(I)
   ──────────────────────────────────────────────────────────────────

   Formula:
     F_ms = 0.5·F_fine(I) + 0.3·F_med(I↓2) + 0.2·F_coarse(I↓4)

   Variables:
     I     = iteration field at full resolution
     I↓2   = 2× average-pool downsampled, then bilinear upsampled
     I↓4   = 4× average-pool downsampled, then bilinear upsampled

   How it works:
     The same fold gradient is computed at 3 resolutions:
       Fine   (1×): Hair-thin fold lines, high frequency detail
       Medium (2×): Major fold structures
       Coarse (4×): Large-scale fold patterns

     Blending weights emphasise fine detail (50%) while adding
     structural context from medium (30%) and coarse (20%).
     Result is normalised to [0, 1] per-frame.

7. EDGE RATTLE  R_e(φ,t)
   ──────────────────────────────────────────────────────────────────

   Formula:
     forward_weight  = weight × (sin(φ_rattle) × 0.2 + 1.0)
     reverse_weight  = weight × (cos(φ_rattle) × 0.2 + 1.0)
     φ_rattle(t+1)   = (φ_rattle(t) + Δt × 0.1) mod 2π

   Variables:
     φ_rattle = rattle phase ∈ [0, 2π), initialised randomly
     Δt       = time step (default 1.0)
     weight   = base edge weight in semantic topology

   How it works:
     Every semantic topology edge has a slowly rotating phase.
     The effective weight breathes by ±20% around its base value.
     Forward and reverse traversals see different modulations
     (sin vs cos) — this creates directional asymmetry.

     The 0.1 angular velocity means one full oscillation every
     ~63 time steps.  This is the "quantum rattling" of the
     semantic graph — edges don't have fixed strength.

     Stability check: edge is stable when tension < 0.5 and
     reliability > 0.6.

========================================================================
HOW THE WALLS RIPPLE ACROSS STATE SPACE
========================================================================

The wall ripple at any moment is the composition of all 7 primitives:

  1. Structural fold W sets the wall skeleton (position-dependent)
  2. Cosine drape D adds Ana-Chi-dependent texture (χ-dependent)
  3. Both are blended: wall_surface = (W·twist + D) / scale
  4. The fractal iteration field I is rendered (Julia set)
  5. Fold gradient ∇F detects discontinuities in I
  6. Rattling proximity P amplifies folds near rattle points
  7. Temporal decay M blends current folds with remembered folds
  8. Multi-scale F_ms ensures both fine and coarse folds visible
  9. Edge rattle R_e modulates the semantic graph underneath

The dominant Ana-Chi attractor determines the character:

  boundary     → walls flat, drape silent, memory off
  mirror       → walls symmetric, drape gentle, memory moderate
  true_center  → walls breathing, drape moderate, memory longest
  white_peak   → walls maximal, drape tightest, proximity 1.0
  escape       → walls shattered, drape high-freq, memory shortest
