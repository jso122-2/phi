Here are best practices to keep Claude from wrecking your DAWN repo:

⸻

1. Treat Claude like a junior dev
	•	Diffs only: never let it write files directly. Demand unified diffs + tests.
	•	Allowlist / Denylist:
	•	✅ tests/**, docs/**, dawn/experiments/**, configs.
	•	🚫 core: tick_engine.py, pulse_controller.py, memory/**, sigil_engine.py (unless explicitly testing under canary harness).
	•	Line ceiling: ≤ 200 lines per patch. If bigger, split into tickets.

⸻

2. System prompt (drop in Cursor)

ROLE: You are a patch assistant for DAWN (deterministic, local). 
RULES:
1. Always search for existing logic before creating new code.
2. Respect existing names (SCUP, SHI, rebloom, tracers, pulse, owl, sigil, memory router).
3. Output unified diff + minimal NOTES + new/updated tests. Nothing else.
4. Modify only allowlisted files. Denylisted are read-only context.
5. No new dependencies, no renames, no abstractions.
6. Absolute imports only (from dawn...).
7. Never alter telemetry schemas, manifest keys, or logging IDs.
OUTPUT FORMAT:
- NOTES (≤5 bullets)
- DIFF (unified diff)
- TESTS (unit tests)
- CHECKS (commands to run)

⸻

3. Task template for you to send

TASK: [what to fix, e.g. localize heavy imports in dawn/core/sigil_engine.py]
CONTEXT: [trace, failing test, snippet]
CONSTRAINTS:
- Touch only: [specific files]
- No new deps; no renames; absolute imports only.
- Telemetry untouched.
EXPECTED OUTPUT:
- NOTES
- DIFF
- TESTS
- CHECKS

⸻

4. Your safety gates

Run after every patch:

ruff check .
pyright || mypy
python tools/audit_imports.py
pytest -q
python -m dawn.run --mode canary --ticks 1500

⸻

5. Keep context small

Claude does best when you feed it:
	•	The target file.
	•	Its direct imports (1 hop).
	•	The failing test or trace.
Not the whole repo — that’s where it hallucinates refactors.

⸻

6. Common failure patterns to reject
	•	🔴 Refactors whole module → enforce diff ceiling.
	•	🔴 Adds helper abstractions → rule 5 bans this.
	•	🔴 Changes schema → immediate reject, separate migration ticket.
	•	🔴 No tests → reject; every patch must ship with one.

⸻

⚡ Bottom line: Claude can be your junior contractor inside Cursor if you pin it with system prompt + task template + hard gates. Without those, it’s a wrecking ball.
